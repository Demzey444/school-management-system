# School Management System

## 📚 Project Overview

The School Management System is a web-based application designed to help schools manage students, teachers, classes, and other school-related information in an organized and efficient way.

This project is being developed as part of my MMS3 NIIT project.

## 🎯 Project Goal

The goal of this project is to create a simple and user-friendly system that reduces manual school record management and makes it easier to store, manage, and access school information.

## ✨ Main Features

- Student registration and management
- Teacher management
- Class management
- Student records management
- Search and view student information
- REST API for communication between the frontend and backend
- Data validation
- Automated testing
